# Matriz PCI Completa

Nueva implementación integral de la Matriz PCI.

## Objetivo

Construir una sola aplicación a partir de la matriz original, conservando su funcionamiento y agregando dentro del mismo flujo:

- carga horaria semanal por espacio;
- organización por cuatrimestres C1–C10;
- Seminarios;
- Proyectos;
- Proyectos Sociocomunitarios Solidarios;
- mapa curricular;
- validación de cobertura y carga horaria;
- acceso y persistencia para las cuatro escuelas.

## Principios de desarrollo

1. La matriz original es la base funcional.
2. No se reemplazan la bolsa de contenidos, la selección múltiple, el arrastre, los agrupamientos, los cierres ni los informes.
3. Los nuevos formatos usan la misma base de contenidos y el mismo estado de la propuesta.
4. No se usan aplicaciones paralelas, launchers encadenados ni editores separados como solución final.
5. El repositorio original `Matriz-PCI` no se modifica desde este proyecto.

## Estado

Repositorio inicializado. La implementación se realizará en la rama `desarrollo` y se incorporará a `main` únicamente después de validación funcional.
